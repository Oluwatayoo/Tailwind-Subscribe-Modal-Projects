# Tailwind Subscribe Modals

A collection of custom **subscribe modals and cards** built with **Tailwind CSS** as part of my practice projects.

I created this repo to improve my Tailwind skills after learning and completing the Subscribe Card mini Project Brad developed in Brad Traversy’s Tailwind course.  
To push myself further, I searched for **real Figma designs** and coded them from scratch, focusing on layout, responsiveness, and component reusability.
